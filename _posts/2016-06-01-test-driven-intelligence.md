Wow, my first blog! A little bit about myself, for the past eight years
I've been a Quant Developer. What's a Quant Developer you ask, well its
someone who codes and develops pricing models and algorithms in the financial 
industry. As you might suspect, it's not like it was in years past, things
have been getting worse...

[![img](http://img.youtube.com/vi/wYlptbR0Dkw/0.jpg)](http://www.youtube.com/watch?v=wYlptbR0Dkw){:height="180px" width="180px" border="10"}


When things get bad and you've invested time and experience in 
an industry, it's still tough to move into something different. There is hope 
though. Recently I read a good article that speaks about [how you can
transfer skills into another industry](http://jobsinme.com/misc/page.aspx?pagenum=five-ways-transfer-skills-other-industry), which gave me an idea on starting this blog
**Test Driven Intelligence**. I'm so glad that I've been coding. The cool thing
about being a developer is that there are a lot of transferable skills, but
I have to be humble and say that there is a lot that I have to learn. So
this blog is going to chronicle my progress down this path from financial 
prediction/optimization to retail web recommendation. I might have eaten an
atomic pepper, but hey if these guys can do it, why not...

[![img](http://img.youtube.com/vi/J7L9THry9QM/0.jpg)](http://www.youtube.com/watch?v=J7L9THry9QM){:height="180px" width="180px" border="10"}


Jokes aside, I'm really excited about this. In the past I loved using **Test 
Driven Development** for financial algorithms, now I am going to 
use TDD to port my knowledge into retail web recommendation using **Machine
Intelligence**. So if you haven't guessed, you can see how I came up with
my blogs theme by following the words in bold. 

Another reason to be excited, is its going to be very cool learning about the 
front-end. I've done some prototyping on the web in the past, but I haven't spent the time seriously learning these tools and technologies. We live in a world that is 
very web-centric, so its important to be able to showcase and demonstrate on 
the web. In the last two months I've been helping out on a Python Django project, 
which has been great. I have also been discovering the magic of Ruby with a very 
cool web development course by [The Firehose Project](http://http://www.thefirehoseproject.com/). I can't say how impressed I am with their course and how awesome 
they are!
