## Theme
This blog is using [Jekyll](http://jekyllrb.com). Jekyll is very cool and
it's a great way to write a blog with markdown. I adapted a great 
implementation from [Jonathan Pike](http://github.com/jonathanpike/personally-developed), I love the one column animation for content in this repository!

## Tools
This is a plug for some of the cool tools I used to develop my website: 

* [Jekyll](http://jekyllrb.com) - As I said, Jekyll is awesome and
  does a lot of magic. Also, let's not forget [Ruby](https://www.ruby-lang.org) 
  (Harry Potter, if he was a developer, would use this language).

* [Github](https://github.com) - Great way to host your website by using
  GitHub Pages.

* [Bootstrap](http://getbootstrap.com) - Bootstrap is a fantastic CSS
	framework, it makes "molta bella" web pages. 

* [Vim](http://www.vim.org) - vim is very cool!

* [tmux](https://tmux.github.io) - Cut down on all your screens, save lots of
  money, save the planet and be a keystroke wizard.
